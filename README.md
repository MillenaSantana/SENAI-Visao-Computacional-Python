## 💜 SOBRE O PROJETO

Este repositório reúne atividades práticas de **Visão Computacional**, desenvolvidas durante o curso de Programação em Inteligência Artificial Generativa do SENAI.

Os projetos exploram processamento de imagens, identificação de objetos, detecção facial e reconhecimento de pessoas em tempo real.

**Principais conceitos:**
- Processamento digital de imagens
- Manipulação de pixels e cores
- Detecção de objetos por contornos
- Detecção facial com Haar Cascade
- Reconhecimento facial utilizando LBPH

---

## 🚀 PROJETOS DESENVOLVIDOS

### 01 | Como o Computador Vê

Exploração da representação digital de imagens, conversão para tons de cinza e análise de matrizes de pixels.

**Tecnologias:** Python e OpenCV.

[![VER PROJETO](https://img.shields.io/badge/VER_PROJETO-7C3AED?style=for-the-badge&logo=github&logoColor=white)](./01-Como-o-Computador-Ve/)

---

### 02 | Detecção de Objetos

Identificação de formas geométricas utilizando técnicas de limiarização, análise de contornos e caixas delimitadoras.

**Tecnologias:** Python e OpenCV.

[![VER PROJETO](https://img.shields.io/badge/VER_PROJETO-9333EA?style=for-the-badge&logo=github&logoColor=white)](./02-Deteccao-de-Objetos/)

---

### 03 | Detecção Facial

Sistema capaz de localizar rostos em fotografias utilizando o classificador Haar Cascade.

**Tecnologias:** Python e OpenCV.

[![VER PROJETO](https://img.shields.io/badge/VER_PROJETO-A855F7?style=for-the-badge&logo=github&logoColor=white)](./03-Deteccao-Facial/)

---

### 04 | Reconhecimento Facial em Tempo Real

Aplicação que permite cadastrar pessoas, treinar um reconhecedor facial utilizando LBPH e identificar rostos pela webcam.

**Funcionalidades:**
- Cadastro facial por captura de imagens
- Treinamento do modelo LBPH
- Reconhecimento facial em tempo real
- Identificação de rostos desconhecidos

**Tecnologias:** Python, OpenCV e NumPy.

[![VER PROJETO](https://img.shields.io/badge/VER_PROJETO-C084FC?style=for-the-badge&logo=github&logoColor=white)](./04-Reconhecimento-Facial/)

## ⚙️ COMO EXECUTAR

**1. Clone o repositório:**

```bash
git clone https://github.com/MillenaSantana/SENAI-Visao-Computacional-Python.git
```

**2. Acesse a pasta:**

```bash
cd SENAI-Visao-Computacional-Python
```

**3. Instale as dependências:**

```bash
pip install "opencv-contrib-python<5" numpy
```

**4. Acesse a pasta do projeto desejado e execute seu arquivo Python.**

Para os projetos que processam fotografias, utilize imagens próprias ou autorizadas.
